# 直链 — 飞牛 fnOS 原生 FPK

轻量飞牛应用：安装后桌面出现 **直链** 图标。

## 行为

| 当前访问方式 | 点击直链后 |
|-------------|-----------|
| **域名**（DDNS / FN ID / 反代等） | 自动跳转到对应内网/公网 IP 的 `5566` 端口 |
| **IP 直连** | 在窗口内列出端口 ≥ 7000 的可访问地址，点击新标签打开 |

## 工作原理

1. 桌面入口在飞牛内部 iframe 中打开启动页。
2. **域名访问**：请求 `api/info.json` 获取 IP，跳转到 `http://{ip}:5566/`。
3. **IP 访问**：请求 `api/services.json`，CGI 扫描系统 TCP 监听端口（排除本机回环、端口 < 7000），列表仅显示完整 URL。

## 构建 .fpk

```bash
bash scripts/build-fpk.sh
# 产物：dist/zhilian-1.0.7.fpk
```

## 安装

飞牛 **应用中心 → 设置 → 手动安装应用**，选择生成的 `.fpk`。

## 配置

| 变量 | 文件 | 说明 |
|------|------|------|
| `TARGET_PORT` | `app/ui/index.cgi`、`app/www/index.html` | 域名访问时的跳转端口（默认 5566） |
| `MIN_LIST_PORT` | `app/ui/index.cgi` | IP 列表最小端口（默认 7000） |
